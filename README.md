# Ferresa — Sitio web comercial

Proyecto de **AG Solutions** para **Ferresa** (Medellín y Barranquilla, Colombia).

Sitio comercial orientado a conversión (web → WhatsApp).

## Stack

- React 19 · Vite 6 · TypeScript · Tailwind CSS 4 · React Router 7

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Variables de entorno

Copia `.env.example` a `.env`.

## Rutas

| Ruta | Estado |
|------|--------|
| `/` | Home |
| `/proyectos` | Listado con proyectos reales |
| `/proyectos/:slug` | Detalle / 404 |
| `/servicios` | Servicios + productos confirmados |
| `/nosotros` | Empresa |
| `/contacto` | Cotización → WhatsApp |
| `/privacidad` | Política de Tratamiento de Datos (Ley 1581) |
| `/terminos` | Términos y Condiciones |
| `*` | 404 |
